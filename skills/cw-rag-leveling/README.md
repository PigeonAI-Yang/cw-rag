# CW RAG Leveling（子 Skill）

为 MapleStory Classic World（CW）玩家按「经验/刀」排出最优练级刷怪路线。

这是 [cw-rag](../..) 母 Skill 的子 Skill。母 Skill 负责通用静态数据查询；本子 Skill 只做练级决策。

## 它解决什么问题

「我该去哪打怪、打哪只最划算？」

普通攻击每次只打一只怪，所以真正决定效率的是：

```
经验/刀 = 每只经验 ÷ 需要刀数
需要刀数 = ceil(怪物血量 ÷ 单刀伤害)
```

这个值越高，每挥一刀换来的经验越多。本工具就是按它排序。

## 快速开始

需要一个已构建的 CW RAG 快照。复用母 Skill 已知的 `--data-dir`。

```powershell
# 用你游戏里实测的单刀伤害
py -3 scripts\cw_calc.py --data-dir "<快照目录>" --level 30 --damage 131

# 想要机器可读结果
py -3 scripts\cw_calc.py --data-dir "<快照目录>" --level 30 --damage 131 --json
```

工具会先列出「能一两刀砍死的怪」，再给完整排序表。若该等级打不到两刀，会直接说明这是数值结构，并改用经验/刀排序。

## 参数

| 参数 | 作用 | 默认 |
| --- | --- | --- |
| `--data-dir` | 快照目录（含 `catalog.sqlite`） | 必填 |
| `--damage` | **游戏内实测的单刀伤害** | 必填 |
| `--level` | 角色等级，用于推算等级下限 | 无 |
| `--level-gap` | 只考虑不低于（等级 − 此值）的怪 | 15 |
| `--min-level` / `--max-level` | 直接指定怪物等级范围 | 无 / 110 |
| `--min-nodes` | 单张地图至少有几只这种怪 | 8 |
| `--max-hits` | 最多几刀能杀 | 3 |
| `--atk-cap` | 只考虑攻击力不高于此值的怪 | 无 |
| `--max-pdd` | 只考虑物防字段不高于此值的怪 | 无 |
| `--no-defence` | 关闭减伤折算 | 关（即默认折算） |
| `--top` | 显示前几名 | 15 |
| `--json` | 输出 JSON | 关 |

## 网页版计算器

`web\cw-calculator.html` 是同一套逻辑的图形界面，适合反复试参数。

三个文件必须放在一起才能打开：

- `web\cw-calculator.html`
- `web\mobs.js`
- `web\gear.js`

后两个由 `scripts\export_web_data.py` 从快照生成：

```powershell
py -3 scripts\export_web_data.py --data-dir "<快照目录>"
```

它们属于客户端派生数据，已在母仓库 `.gitignore` 中排除，不入库。

## 重要限制

**1. `--damage` 必填，必须来自玩家实测。**

客户端文件里没有伤害计算公式，无法从中推出玩家实际伤害。

这个工具**早期版本试过自动估算，结果被证伪**：按常见公式估出上限 115，实测只有 77，**高估了 50%**。所以现在取消了估算——不填 `--damage` 直接报错，不产出误导性结果。

**2. 减伤规则默认启用，但它是候选值。**

```
实际伤害 = 原始伤害 × 100 ÷ (物防 + 100)
```

| 物防 | 伤害剩 |
| --- | --- |
| 0 | 100% |
| 30 | 76.9% |
| 100 | 50% |
| 500 | 16.7% |

**来源：** [maplestory-classic-server](https://github.com/mainlandhero/maplestory-classic-server) 收录的社区指南，标注为**候选**。该项目的客户端逆向确认了武器倍率表（8 个武器族全部对上），但防御公式只找到常量池的间接旁证。

**物防 0 时这条规则是恒等变换**，所以它与零物防实测不矛盾——但也不构成验证。

**自行验证的方法：** 打一只物防 30 的怪（如 Dark Stump）看伤害上限。落在 `原值 × 0.769` 说明反比例成立；落在 `原值 − 30` 说明是减法；不变说明物防无效。

**不想承担不确定性：** 加 `--no-defence` 关闭折算，或用 `--max-pdd 0` 只打物防 0 的怪。

**3. 「一两刀砍死」只在低级成立。**

怪物血量增长快于玩家伤害。大致：30 级前后两刀，40 级起三刀以上，50 级后常需 8～13 刀。高级别请改用「经验/刀」标准。

**4. 快照中不存在的数据。**

掉落率、服务器倍率、活动加成，客户端文件里都没有。

## 数据来源

怪物与装备数据来自本地 CW 客户端 `Data` 目录，经 cw-rag 构建为只读 SQLite 快照。客户端文件始终只读，本工具不访问网络、不调用模型 API、不自动刷新。
