# CW RAG Leveling（子 Skill）

为 MapleStory Classic World（CW）玩家排出最优练级刷怪路线。

这是 [cw-rag](../..) 母 Skill 的子 Skill。母 Skill 负责通用静态数据查询；本子 Skill 只做练级与武器决策。

## 它解决什么问题

「我该去哪打怪、哪种武器更快、要打多久？」

主指标是**每秒经验 = 每只经验 ÷ 杀一只所需秒数**。它同时包含三件事：

```
实际伤害   = 原始伤害 × 100 ÷ (物防 + 100)
需要刀数   = ceil(怪物血量 ÷ 实际伤害)
攻击间隔   = 从客户端帧延迟算出的真实挥刀时间
击杀秒数   = 需要刀数 × 攻击间隔
每秒经验   = 每只经验 ÷ 击杀秒数
```

比起只报「几刀」，这个口径能正确区分攻速不同的武器——同样三刀，攻速 4 花 2.2 秒，攻速 8 花 2.7 秒。

## 快速开始

需要一个已构建的 CW RAG 快照。复用母 Skill 已知的 `--data-dir`。

```powershell
# 用实测伤害 + 武器攻速标签，得到「几秒一只」与「每秒经验」
py -3 scripts\cw_calc.py --data-dir "<快照目录>" --level 16 --damage 52 --weapon 1302002 --speed-tag 4

# 不给武器时退化为按经验/刀排序
py -3 scripts\cw_calc.py --data-dir "<快照目录>" --level 16 --damage 52
```

## 参数

| 参数 | 作用 | 默认 |
| --- | --- | --- |
| `--data-dir` | 快照目录（含 `catalog.sqlite`） | 必填 |
| `--damage` | **游戏内实测的单刀伤害** | 必填 |
| `--weapon` | 武器 ID（如 `1302018`），用于算攻击间隔 | 无 |
| `--speed-tag` | 武器攻速标签（1..8），与 `--weapon` 同时使用 | 无 |
| `--max-seconds` | 最多几秒能杀 | 无 |
| `--level` | 角色等级，用于推算等级下限 | 无 |
| `--level-gap` | 只考虑不低于（等级 − 此值）的怪 | 15 |
| `--min-level` / `--max-level` | 直接指定怪物等级范围 | 无 / 110 |
| `--min-nodes` | 单张地图至少有几只这种怪 | 8 |
| `--max-hits` | 最多几刀能杀 | 3 |
| `--atk-cap` | 只考虑攻击力不高于此值的怪 | 无 |
| `--max-pdd` | 只考虑物防字段不高于此值的怪 | 无 |
| `--no-defence` | 关闭减伤折算 | 关（即默认折算） |
| `--top` | 显示前几名 | 15 |
| `--json` | 输出 JSON | 关 |

## 攻速数据的来源

攻击间隔不是估的。三个输入：

| 输入 | 来源 | 级别 |
| --- | --- | --- |
| 每个动作的逐帧 `delay` | 客户端 `Character_000.wz/00002000.img` | **从客户端读出** |
| 每把近战武器 3 挥砍 + 2 刺击 | 客户端 `Character.wz/Weapon` 动作数 | **从客户端读出** |
| 帧延迟的缩放规则 | 社区指南 | **候选** |

缩放公式：

```
ScaledFrame    = trunc(FrameDelay × (10 + attackSpeed) / 16)
AnimationTime  = 30 × ceil(Σ ScaledFrame / 30)
```

两个锚点让候选规则可信一点：`attackSpeed` 为 6 时系数恰好是 1（恒等变换），且指南的算例（长柄攻速 8 → 900 ms）能用帧延迟表复现。

**实测区间：攻速 4 ≈ 720 ms，攻速 8 ≈ 900 ms，两端只差 23%。** 不要夸大成「慢一半」——早期版本按每级 12% 估过，把 23% 估成了 48%，据此得出的结论是错的。

重新从客户端提取（客户端更新或需要复核时）：

```powershell
py -3 scripts\read_client_frames.py --client "<客户端 Data 目录>"
```

它会打印逐帧 `delay` 并与内置表对比，不一致时以非零码退出。

## 网页版计算器

`web\cw-calculator.html` 是同一套逻辑的图形界面。三个文件必须放在一起：

- `web\cw-calculator.html`
- `web\mobs.js`
- `web\gear.js`（含每把武器的挥刀毫秒）

后两个由 `scripts\export_web_data.py` 从快照生成：

```powershell
py -3 scripts\export_web_data.py --data-dir "<快照目录>"
```

它们属于客户端派生数据，已在母仓库 `.gitignore` 中排除，不入库。

## 重要限制

**1. `--damage` 必填，必须来自玩家实测。**

客户端文件里没有伤害计算公式，无法从中推出玩家实际伤害。

这个工具**早期版本试过自动估算，结果被证伪**：按常见公式估出上限 115，实测只有 77，**高估了 50%**。所以现在取消了估算——不填 `--damage` 直接报错。

**2. 有 `--speed-tag` 时，报刀数也要报秒数。**

只报刀数会误导：攻速不同的武器，同样的刀数花的时间不同。

**3. 减伤规则默认启用，但它是候选值。**

```
实际伤害 = 原始伤害 × 100 ÷ (物防 + 100)
```

| 物防 | 伤害剩 |
| --- | --- |
| 0 | 100% |
| 30 | 76.9% |
| 100 | 50% |
| 500 | 16.7% |

**来源：** [maplestory-classic-server](https://github.com/mainlandhero/maplestory-classic-server) 收录的社区指南，标注为**候选**。该项目的客户端逆向确认了武器倍率表（8 个武器族全部对上），但防御公式只找到常量池的间接旁证。

**物防 0 时这条规则是恒等变换**，所以它与零物防实测不矛盾——但也不构成验证。

**自行验证的方法：** 打一只物防 30 的怪（如 Dark Stump）看伤害上限。落在 `原值 × 0.769` 说明反比例成立；落在 `原值 − 30` 说明是减法；不变说明物防无效。

**不想承担不确定性：** 加 `--no-defence` 关闭折算，或用 `--max-pdd 0` 只打物防 0 的怪。

**4. 「一两刀砍死」只在低级成立。**

怪物血量增长快于玩家伤害。高级别请改用「每秒经验最高」标准。

**5. 双手武器不能同时装盾。**

盾牌同等级防御远高于防具（70 级盾 192），是「不喝药」的核心。推荐双手武器时必须说明这个代价。

**6. 快照中不存在的数据。**

掉落率、服务器倍率、活动加成，客户端文件里都没有。

## 数据来源

怪物、装备与攻速帧延迟来自本地 CW 客户端 `Data` 目录，经 cw-rag 构建为只读 SQLite 快照，或由 `read_client_frames.py` 直接读取。客户端文件始终只读，本工具不访问网络、不调用模型 API、不自动刷新。
