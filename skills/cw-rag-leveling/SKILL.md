# CW 练级路线排序

用本地 CW RAG 快照里的怪物静态数据，回答「现在该打什么怪、去哪打」。这是 [cw-rag](../cw-rag/SKILL.md) 的子 Skill：母 Skill 负责通用查询，这里专门做练级决策。

## 先决条件

需要一个已构建的 CW RAG 快照（含 `catalog.sqlite`）。复用母 Skill 已知的 `--data-dir`。快照缺失或版本不符时，按母 Skill 的说明处理，不要在这里重新构建。

**客户端文件保持只读。** 本工具只读快照，不访问网络、不调用模型 API、不自动刷新。

## 核心工具

`scripts\cw_calc.py` 相对本 Skill 目录解析，不要相对当前工作目录。

```powershell
py -3 "<本Skill目录>\scripts\cw_calc.py" --data-dir "<快照目录>" --level 30 --damage 131
```

常用参数：

| 参数 | 作用 |
| --- | --- |
| `--data-dir` | 必填。快照目录 |
| `--damage` | **必填。游戏内实测的单刀伤害** |
| `--level` | 角色等级，用于推算等级下限 |
| `--level-gap` | 只考虑不低于（等级 − 此值）的怪，默认 15 |
| `--min-level` / `--max-level` | 直接指定怪物等级范围 |
| `--min-nodes` | 单张地图至少要有多少只这种怪，默认 8 |
| `--max-hits` | 最多几刀能杀，默认 3 |
| `--atk-cap` | 只考虑攻击力不高于此值的怪（更安全） |
| `--max-pdd` | 只考虑物防字段不高于此值的怪（避开打不动的） |
| `--json` | 输出 JSON，便于进一步处理 |

## 排序依据

**经验/刀 = 每只经验 ÷ 需要刀数**，其中需要刀数 = `ceil(怪物血量 ÷ 单刀伤害)`。

这个值越高，代表每挥一刀换来的经验越多。能一刀秒的怪，经验/刀 = 它的全部经验。

## 必须遵守的判断规则

**1. `--damage` 必填，且必须来自玩家实测。**

客户端文件里**没有伤害计算公式**，任何人都无法从中推出玩家实际打多少。

这个工具**早期版本试过自动估算，结果是错的**：它按常见公式估出 115 的上限，而实测只有 77，高估了 50%。所以现在取消了估算——**没填 `--damage` 就直接报错**，不产出误导性排序。

用户没给实测伤害时：**请他去游戏里打一下，把屏幕上的数字报回来**，不要替他估。

**2. 物防字段只展示，不进公式。**

- 物防 = 0：实测确认面板伤害可直接套用（红蜗牛物防 0，实测与面板吻合）。
- 物防 &gt; 0：实际伤害会低于面板，但**客户端没有给出换算方式**。

工具会在输出里标出物防不为 0 的怪并告警，**但不会把它算进刀数**。推荐时优先选物防 0 的怪；`--max-pdd 0` 可以只看这些。**不要自己编一个防御减免公式。**

**3. 「一两刀砍死」只在低级成立，不要硬套到高级。**

怪物血量增长快于玩家伤害，这是数值结构。当用户在高级别要求「一两刀」时，**直接说明这一点，并改用「经验/刀最高的怪」**。这不是装备问题。

**4. 不要为了「更弱」而推荐远低于用户等级的怪。**

低级怪照样给经验，所以纯按经验/刀排会永远推荐最弱的怪。用 `--level-gap`（默认 15）限制等级差。

**客户端里没有定义等级差与经验衰减的关系**，所以这个参数由用户决定，只能提示，不能替他断言。

## 使用未知字段的限制

快照中怪物还有魔防、闪避等字段，**含义未经证实**。**不要把这类字段编进任何公式**，也不要用它们解释伤害。

物防（`PDDamage`）是唯一做了实测验证的：物防 0 时面板伤害直接生效。即便如此，**工具也只展示它、按它筛选，不推算减免**。

同理，`reqJob` 之类的原始掩码不要翻译成「某职业可穿」。

## 输出要求

领先给出可执行结论：**打哪只怪、去哪个地图、大概几刀**。然后按需给排序表。

保留英文原文怪名和地图名（快照只有英文），但在中文回答里补上中文说明。不要编造中文译名当成源数据。

## 配套建议

装备与加点只讲与「省药、防御、攻速」相关的要点，并说明理由来自哪个字段：

- 武器：单手剑，攻击速度数值越小越快。**不要推荐双手武器**——它不能同时装备盾牌。
- 盾牌：同等级下防御远高于防具，是减伤主力。
- 鞋子：回避是唯一的免伤来源。
- 加点：优先「HP 恢复强化」（每 10 秒自动回血），其次减伤技能，最后输出。
- 只用普通攻击时全程不耗蓝、不扣血，因此**不需要买血药蓝药**。

装备掉落率、服务器倍率、活动加成在快照中都不存在，不要声称知道。

## 可视化计算器

`web\cw-calculator.html` 是同逻辑的网页版，给用户自己反复试参数用。它依赖同目录的 `mobs.js`、`gear.js`；这三个文件必须放在一起才能打开。生成这两个数据文件用 `scripts\export_web_data.py`。

网页版与命令行工具口径必须一致：都按「经验/刀」排序，都要标注估算与实测的区别。
